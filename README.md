# Create: Transmission!

This addon for create adds the Transmission Chain! Its a useful block that can be used to transfer rotational power between belt.

It can be used to connect right angle belts, consecutive belts and even belts that are on top of each other!

![](https://media.forgecdn.net/attachments/description/1354280/description_206dec95-bb0f-4902-9a1c-8c04cde6ea5d.gif)

It is designed to simplify belt powering and avoid cluncky setup with gearboxes and encased chain drives without making them obsolete! The transmission chain in fact can be only placed on belts!
